# Includes Directory

This directory contains shared PHP include files for the Football Stats Dashboard.

## Files
- `table-view.php`: Main logic for rendering league tables and controls
- `table-view-date-helper.php`: Helper for fetching the first match date for a matchweek
- `header.php`, `footer.php`: Shared header/footer for all dashboard pages

These files are used across multiple tabs and views for consistent UI and data access.
