# Premier League 2025-2026 Tabs

This directory contains all the PHP files for the Premier League 2025-2026 dashboard tabs. Each file represents a different view or feature for the season, such as league tables, blocks, relegation, Leeds-specific views, and comparison tools.

## Tabs Overview
- `table.php`, `table2.php`: Main league table views.
- `blocks-1.php` to `blocks-5.php`, `blocks-dynamic.php`, `blocks-overview.php`: Various block-based breakdowns and analytics.
- `leeds.php`, `leeds2.php`, `leeds3.php`: Leeds United focused views.
- `relegation.php`, `relegation2.php`: Relegation battle analysis.
- `compare.php`: Compare any two matchweeks or live vs. snapshot.
